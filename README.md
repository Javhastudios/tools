# Javhastudios Tools

Colección de herramientas web para producción musical y mezcla. Acceso directo desde el navegador, sin instalación.

🔗 **[javhastudios.github.io/tools](https://javhastudios.github.io/tools/)**

---

## Herramientas

| Herramienta | Descripción |
|---|---|
| ⏱ **Pomodoro Timer** | Gestión de sesiones de trabajo para evitar fatiga mental y auditiva |
| 🎚 **BPM Calculator** | Tap tempo, delays, reverb y divisiones rítmicas al BPM |
| 🎹 **Hz ↔ Nota** | Equivalencia entre Hz, notas musicales, piano interactivo y rango de instrumentos |
| 🎛 **Visualizador de Compresión** | Curva de transferencia, envolvente animada y Gain Reduction en tiempo real |
| 🎵 **Generador de Tonos** | Osciladores, ruido blanco y rosa, barrido de frecuencias y presets de referencia |
| 🎼 **Círculo de Quintas** | Tonalidades, acordes diatónicos, correspondencias armónicas y teclado interactivo |
| ⚖️ **Pan Checker** | Goniómetro, VU L/R, correlación de fase, balance en dB, inversión de canales y generador de ruido de prueba |

---

## Tecnología

HTML5 · CSS3 · JavaScript puro · Web Audio API — sin frameworks, sin dependencias externas.
